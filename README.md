# getopencandle.com

The website for [OpenCandle](https://github.com/getopencandle/opencandle), a free, source-available desktop charting app for Windows.

- Visit the site: https://getopencandle.com
- Download the app: [latest release](https://github.com/getopencandle/opencandle/releases/latest)
- Source, issues and discussions: [getopencandle/opencandle](https://github.com/getopencandle/opencandle)

The site is a single static page with no trackers, analytics or external scripts.
